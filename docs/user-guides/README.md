# Panduan Penggunaan Aplikasi per Role

Dokumen Microsoft Word berikut dipisahkan berdasarkan role agar prosedur dan batas kewenangan tidak tercampur.

| Role | Dokumen | Cakupan utama |
|---|---|---|
| `ADMIN_GUDANG` | [Panduan Admin Gudang](Panduan-Admin-Gudang.docx) | Dashboard, master barang, stok, penerimaan, koreksi, retur/tukar, pemantauan invoice, laporan, pengguna, dan log aktivitas |
| `ADMIN_KASIR` | [Panduan Admin Kasir](Panduan-Admin-Kasir.docx) | POS tiga langkah, pembayaran tunai/transfer/tempo/split, transaksi ditahan, nota, invoice, pembayaran, edit, retur/tukar, dan rekonsiliasi |
| `ADMIN_NONGUDANG` | [Panduan Admin Non-Gudang](Panduan-Admin-Non-Gudang.docx) | Katalog trading, konsumen, invoice satu toko sumber, pembayaran tempo, pembelian, laporan, PDF, dan Excel |

## Cara membuka

1. Unduh atau buka file `.docx` dengan Microsoft Word, LibreOffice Writer, atau aplikasi pengolah dokumen yang kompatibel.
2. Di Microsoft Word, klik kanan daftar isi lalu pilih **Update Field > Update entire table**.
3. Gunakan dokumen yang sesuai dengan role akun. Jangan menjalankan prosedur dari role lain melalui URL langsung.
