# User Guides by Role

Panduan penggunaan aplikasi tersedia sebagai dokumen Microsoft Word terpisah untuk setiap role aktif.

| Role | Dokumen | Cakupan |
|---|---|---|
| `ADMIN_GUDANG` | [Panduan Admin Gudang](../../user-guides/Panduan-Admin-Gudang.docx) | Persediaan, penerimaan, koreksi stok, retur/tukar, pengawasan invoice, laporan, pengguna, dan log aktivitas |
| `ADMIN_KASIR` | [Panduan Admin Kasir](../../user-guides/Panduan-Admin-Kasir.docx) | POS, pembayaran, nota, invoice/piutang, retur/tukar, dan rekonsiliasi kasir |
| `ADMIN_NONGUDANG` | [Panduan Admin Non-Gudang](../../user-guides/Panduan-Admin-Non-Gudang.docx) | Katalog trading, konsumen, invoice satu toko, pembayaran, pembelian, dan laporan |

Setiap dokumen memuat hak akses, langkah kerja, kontrol hasil, checklist akhir, troubleshooting, batas kewenangan, dan riwayat revisi. Dokumen tidak memuat kredensial atau data pelanggan.

## Penggunaan

1. Distribusikan hanya panduan yang sesuai dengan role pengguna.
2. Perbarui daftar isi di Microsoft Word melalui **Update Field > Update entire table**.
3. Revisi panduan bila menu, label, role guard, atau aturan domain berubah.

Indeks file: [README panduan role](../../user-guides/README.md).
